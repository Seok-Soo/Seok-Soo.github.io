# Seok Jongsoo Resume & Backend Portfolio

석종수의 백엔드 개발자 이력서 겸 포트폴리오입니다. 경력과 기술을 먼저 확인하고 프로젝트의 문제 해결 과정과 검증 자료까지 이어서 볼 수 있도록 구성했습니다.

## 로컬 실행

```bash
python -m http.server 8000
```

브라우저에서 `http://localhost:8000`을 열면 현재 메인 포트폴리오를 볼 수 있습니다. 이전 버전은 `/portfolio-v1/`, `/portfolio-v2/`, `/portfolio-v3/`, `/portfolio-v4/`에서 볼 수 있습니다.

v3는 GETDDO와 최우수 훈련생 수상 내용을 추가하기 전인 `825fe9a` 커밋의 화면, 스타일, 스크립트와 로컬 이미지를 보존한 버전입니다.

v4는 이번 세션의 기술 섹션 축소, 활동·수상 정리, 대표 프로젝트 카드, 파란색 테마 변경 전인 `7872754` 커밋의 화면, 스타일, 스크립트와 로컬 이미지를 보존한 버전입니다. 메인으로 이동하지 않고 독립적으로 열립니다.

로컬 서버는 `Ctrl+C`로 종료할 수 있습니다.

## 구성

- `index.html`, `styles.css`, `script.js`: 현재 메인 포트폴리오
- `portfolio-v1/`, `portfolio-v2/`: 이전 포트폴리오
- `portfolio-v3/`: GETDDO 추가 전 v3 보존본
- `portfolio-v4/`: 이번 세션 작업 전 v4 보존본 (`7872754`)
- `assets/`: 프로필, 프로젝트 이미지, 기술 아이콘
