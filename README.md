# Seok Jongsoo Resume & Backend Portfolio

석종수의 백엔드 개발자 이력서 겸 포트폴리오입니다. 경력과 기술을 먼저 확인하고 프로젝트의 문제 해결 과정과 검증 자료까지 이어서 볼 수 있도록 구성했습니다.

## 로컬 실행

```bash
python -m http.server 8000
```

브라우저에서 `http://localhost:8000`을 엽니다.

## 구성

- `index.html`: 이력서와 프로젝트 콘텐츠
- `styles.css`: 화면, 모바일, A4 인쇄 레이아웃
- `assets/`: AIDEO와 뿌리오 프로젝트 이미지

상단의 `PDF 저장` 버튼을 누르면 브라우저 인쇄 화면에서 PDF로 저장할 수 있습니다.
